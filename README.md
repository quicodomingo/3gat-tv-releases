# 3Gat for Google TV — releases

APKs of a **prototype** Google TV app (a design proposal, not an official app). The app checks
`latest.json` from the latest release to offer in-app updates.

Each release has:
- `3gat-<version>.apk`
- `latest.json`: `{versionCode, versionName, apk, size, sha256, notes}` (notes in Catalan)
